\section*{Data availability statement}

The data that support the findings of this study are openly available at the following URL/DOI:
\url{https://github.com/Satyabrat2005/QLO---Quantum-Langevin-Optimisation}, archived at
\textbf{[Zenodo DOI from I7]}. The repository holds the code for every experiment, the result files behind every
figure and table, and the scripts that rebuild them from those files. For each figure panel,
\url{paper/figures/FIGURE_SOURCES.md} names the result file, columns, filters and aggregation it is drawn from, and
\texttt{python -m qlo.paper.figures} regenerates the figures. All results come from classical simulation.
